# Label Printing Guide

This guide explains how to use the label printing functionality in the POS system for printing QR codes and barcodes on label printers.

## Overview

The system supports three types of label printing:

1. **Browser Print** - Uses regular paper with label formatting
2. **ZPL (Zebra Programming Language)** - For Zebra label printers
3. **EPL (Eltron Programming Language)** - For Epson label printers

### Direct Printing vs Command Generation

- **Direct Printing**: Labels are sent directly to connected printers (USB, Network, Serial)
- **Command Generation**: Printer commands are copied/downloaded for manual use

## How to Use

### 1. Access Label Printing

1. Navigate to any inventory item details page
2. Click the "Print Labels" button (green button with printer icon)
3. This opens the Label Print Modal with configuration options

### 2. Configure Label Settings

#### Printer Type
- **Browser Print**: Uses your regular printer with label paper
- **ZPL**: For Zebra label printers (generates ZPL commands)
- **EPL**: For Epson label printers (generates EPL commands)

#### Label Size
Choose from predefined sizes or create custom:
- **Small (25x15mm)**: For small items
- **Medium (50x25mm)**: Standard size (recommended)
- **Large (100x50mm)**: For larger items
- **Address (100x30mm)**: For address labels
- **Shipping (100x150mm)**: For shipping labels
- **Custom**: Define your own width and height

#### Quantity
Set how many labels to print (1-100)

### 3. Print Options

#### Browser Print
- Click "Print Labels" to open the browser print dialog
- Make sure you have label paper loaded in your printer
- The system will format the content specifically for label printing

#### Direct Printing (Recommended)
- Select a connected printer from the list
- Click "Test Connection" to verify printer connectivity
- Click "Print to Label Printer" to send labels directly
- Supports USB, Network, and Serial connections

#### Manual Command Generation
- Click "Manual Config" to set up printer connection manually
- Enter printer details (IP address, port, device path, etc.)
- Click "Test Connection" to verify settings
- Click "Copy Commands" or "Download Commands" for manual use

## Label Printer Setup

### Hardware Requirements
- Label printer (Zebra, Epson, or compatible)
- Label paper/rolls
- USB, network, or serial connection

### Software Setup

#### For Zebra Printers:
1. Install ZebraDesigner or Zebra Setup Utilities
2. Configure printer settings (DPI, label size, etc.)
3. Use the ZPL commands generated by the system

#### For Epson Printers:
1. Install Epson printer drivers
2. Configure label settings in printer properties
3. Use the EPL commands generated by the system

#### For Browser Printing:
1. Load label paper in your regular printer
2. Configure printer settings for label size
3. Use the browser print functionality

## API Endpoints

### Backend API
The system includes a backend API for direct printing and command generation:

#### Generate Commands
```
POST /common/api/inventory/{id}/print-labels/
```

#### Direct Printing
```
POST /common/api/inventory/{id}/print-labels-direct/
```

#### Get Available Printers
```
GET /common/api/inventory/available-printers/
```

#### Test Printer Connection
```
POST /common/api/inventory/test-printer/
```

**Request Body for Direct Printing:**
```json
{
  "printer_type": "zpl|epl",
  "label_size": {
    "width": 50,
    "height": 25
  },
  "quantity": 1,
  "printer_config": {
    "type": "network|usb|serial",
    "ip_address": "192.168.1.100",
    "port": 9100,
    "device_path": "/dev/usb/lp0",
    "baudrate": 9600
  }
}
```

**Response:**
```json
{
  "message": "Successfully printed 1 labels",
  "printer_type": "zpl",
  "label_size": {"width": 50, "height": 25},
  "quantity": 1
}
```

## Troubleshooting

### Common Issues

1. **Labels not printing correctly**
   - Check label size settings
   - Verify printer DPI settings
   - Ensure label paper is loaded correctly

2. **ZPL/EPL commands not working**
   - Verify printer model compatibility
   - Check printer connection
   - Test with printer manufacturer's software

3. **Browser print formatting issues**
   - Check printer settings
   - Verify label paper size
   - Try different label size options

### Printer-Specific Notes

#### Zebra Printers
- Most Zebra printers support ZPL
- Common models: ZD220, ZD230, ZD410, ZD420
- Use ZebraDesigner for testing commands

#### Epson Printers
- Epson label printers support EPL
- Common models: TM-T88VI, TM-T88V, TM-T88VI
- Use Epson printer utilities for configuration

## Advanced Configuration

### Custom Label Sizes
You can create custom label sizes by:
1. Selecting "Custom" in the label size dropdown
2. Entering width and height in millimeters
3. The system will automatically adjust font sizes and layout

### Font Sizing
The system automatically adjusts font sizes based on label dimensions:
- Small labels (≤30mm): Smaller fonts
- Medium labels (≤60mm): Standard fonts  
- Large labels (>60mm): Larger fonts

### QR Code Sizing
QR codes are automatically sized to fit the label:
- Width: 30% of label width
- Height: 40% of label height
- Maximum size: 25mm x 25mm
